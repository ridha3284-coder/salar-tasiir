# راتبي — مسيّر الراتب والميزانية (PWA)

تطبيق ويب تقدّمي بواجهة عربية RTL: مصاريف يومية، أهداف، ديون، سلف، أقساط، خطة سداد الدين والخطة الدائمة، توزيع بالنسب، تقرير شهري PDF وأرشيف، ونسخ احتياطي واستعادة.
بلا خادم وبلا أدوات بناء. البيانات في `localStorage` على جهاز المستخدم فقط.

## الملفات
| الملف | الدور |
|---|---|
| `index.html` | التطبيق كاملاً |
| `manifest.webmanifest` | بيانات التثبيت |
| `sw.js` | العمل بدون إنترنت |
| `icons/` | أيقونات 192 و512 |
| `netlify.toml` | إعداد Netlify (بلا أمر بناء + ترويسات) |
| `.github/workflows/pages.yml` | نشر تلقائي على GitHub Pages |
| `.nojekyll` | يمنع معالجة Jekyll |

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع محتويات هذا المجلد في الجذر (بما فيها المجلدات المخفية `.github`).
2. من Settings ← Pages ← Source اختر **GitHub Actions**.
3. أي push على `main` ينشر التطبيق تلقائياً على `https://USER.github.io/REPO/`.

## النشر على Netlify
1. Add new site ← Import from GitHub ← اختر المستودع.
2. اترك Build command فارغاً، وPublish directory = `.` (يُقرأ من `netlify.toml`).
3. بعد النشر افتح الرابط من الجوال ← «إضافة إلى الشاشة الرئيسية».

## تحويله إلى APK
افتح pwabuilder.com، ألصق رابط الموقع، تأكد من ✅ للـManifest والـService Worker، ثم Android package.

## استيراد البيانات القديمة
الرئيسية ← «استعادة» ← اختر ملف JSON من «مسيّر الميزانية» أو «مسيّر الراتب» أو «راتبي».

## عند تحديث التطبيق
غيّر رقم الإصدار في `sw.js` (`rateby-v2` ← `rateby-v3`) ليُحدَّث الكاش لدى المستخدمين.
